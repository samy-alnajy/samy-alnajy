## 🚀 Featured Projects

### 🧦 Cottonil Sales Data Analysis

> Retail Sales Analytics · Python · BeautifulSoup · Pandas · Excel · Power Query · SQL Server · Power BI

**End-to-end sales analysis project built from raw HTML reports for a retail clothing business.**

- Extracted Arabic RTL data from raw HTML reports using **BeautifulSoup + Pandas**
- Handled **Windows-1256 encoding** and transformed raw reports into structured CSV/Excel data
- Cleaned and transformed data using **Excel + Power Query**
- Built SQL Server analytical tables/views including `sales_master`, `sales_time_analysis`, and `product_performance`
- Created a **5-page Power BI dashboard**
- Covered Executive Overview, Sales Analysis, Product Analysis, Returns Analysis and Customer Behavior
- Analyzed sales, invoices, average basket value, product performance, returns and seasonality

🔗 **Repository:** [cottonil-sales-data-analysis](https://github.com/samy-alnajy/cottonil-sales-data-analysis)
